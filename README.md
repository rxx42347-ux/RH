# Rio AI Studio V0.5 — Mobile Upload Edition

هذه النسخة مصممة لرفع ملفاتها إلى مستودع GitHub من الجوال بدون الحاجة إلى رفع مجلد `api` بشكل مستقل.

## البنية

كل ملفات وظائف الخادم موجودة في جذر المشروع:
- `ai.js`
- `status.js`
- `health.js`

و`vercel.json` يربطها تلقائيًا بالمسارات:
- `/api/ai`
- `/api/status`
- `/api/health`

## Vercel

اترك متغير البيئة الموجود لديك كما هو:

`FAL_KEY`

لا تضع المفتاح داخل GitHub أو JavaScript.

## النشر من الجوال

ارفع **كل ملفات هذه النسخة إلى جذر مستودع RH**. لا تنشئ مجلد `api` ولا ترفع أي ملف منه بشكل مستقل.

بعد الرفع، Vercel يعيد النشر تلقائيًا إذا كان GitHub مربوطًا بالمشروع.

## تنبيه

هذه النسخة تحل مشكلة بنية الرفع فقط. ما زالت وظائف التطبيق التي لم تُنفذ بعد تحتاج تنفيذًا حقيقيًا قبل اعتبار المنتج مكتملًا.
