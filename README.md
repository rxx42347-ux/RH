# Empire Builder V0.3

لعبة إدارة مدينة وإمبراطورية، والهدف النهائي منها إصدار Android.

## أنظمة V0.3
- اقتصاد وخزينة وضرائب.
- سكان ورضا ووظائف ومساكن.
- موارد: غذاء، حديد، خشب، طاقة.
- بناء: مزارع، مساكن، طرق، أسواق، محطات طاقة، مصانع.
- تجارة شراء وبيع مع أسعار متغيرة.
- جيش وتدريب وتطوير وتحـصينات.
- دبلوماسية مع ثلاث دول.
- أبحاث وتقنيات اقتصادية وعسكرية ومدنية.
- أحداث شهرية عشوائية.
- سمعة الدولة.
- حساب دخل وصيانة واستهلاك الغذاء والنمو السكاني.
- حفظ وتحميل محلي.
- واجهة مناسبة للجوال.

## التشغيل
افتح `index.html` في متصفح حديث.

## Android
هذه النسخة ما زالت Prototype ويب. المرحلة التالية بعد تثبيت أنظمة اللعب هي إنشاء مشروع Android فعلي وبناء APK/AAB واختباره على أجهزة Android.

## الإصدارات
كل إصدار جديد يجب أن يتضمن CHANGELOG واضحًا برقم الإصدار والتغييرات.
