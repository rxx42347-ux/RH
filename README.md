# Sentinel V0.1
نموذج أولي لمنصة دفاعية للأمن السيبراني.

## الموجود
- لوحة أمنية حديثة.
- ملخص حالة الأجهزة والتنبيهات.
- سجل أحداث.
- مؤشر حماية.
- زر فحص تجريبي يحاكي سير العمل فقط.
- واجهة متجاوبة للجوال.

## مهم
هذه النسخة **واجهة تجريبية وليست أداة فحص حقيقية**. لا تصل إلى الأجهزة ولا تجمع بيانات ولا تنفذ اختبارات اختراق.

## الاتجاه التالي
- تطبيق/عامل محلي بموافقة المستخدم.
- فحوصات دفاعية حقيقية حسب نظام التشغيل والصلاحيات المتاحة.
- Threat Intelligence.
- إدارة الحوادث والأدلة.
- تقارير PDF.
- لوحة شركات متعددة الأجهزة.
