# Rio AI Studio — V0.2

## هدف النسخة
تعميق النسخة الأولى من واجهة Rio AI Studio وتحويلها من مجرد Mockup إلى **Prototype وظيفي Mobile-first** يمكن اختبار تجربة استخدامه فعلياً قبل ربط الخدمات السحابية.

## ما أصبح يعمل فعلياً
- تنقل كامل بين الرئيسية / إنشاء / القوالب / المشاريع / الحساب.
- حفظ المشاريع محلياً عبر `localStorage`.
- إضافة القوالب إلى قائمة المشاريع.
- فلترة القوالب حسب التصنيف.
- فتح محرر الفيديو.
- استيراد فيديو أو صورة من جهاز الهاتف.
- معاينة الفيديو أو الصورة داخل المحرر.
- تشغيل/إيقاف الفيديو.
- شريط تقدم/تنقل داخل الفيديو.
- Timeline فعلي لعرض الوسائط المستوردة.
- إضافة نص فوق المعاينة.
- فلاتر أساسية للمعاينة.
- تغيير نسبة العرض 9:16 / 16:9 / 1:1.
- واجهة أدوات منفصلة للصوت والنص والوسائط.
- نافذة اشتراكات بخطط Starter / Creator / Pro / Studio.
- حفظ طلبات AI كـمشاريع دون الادعاء بأن التوليد الحقيقي متصل بعد.
- تصميم عربي RTL ومتجاوب مع الجوال.

## ما لم يتم تزويره
توليد الفيديو/الصورة والصوت، تسجيل الدخول، الدفع، التخزين السحابي، والتصدير النهائي ليست خدمات حقيقية في V0.2. الواجهة مهيأة لربطها بمحركات فعلية في المرحلة التالية.
