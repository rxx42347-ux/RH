# Empire Builder — V4.0

V4.0 تركز أولاً على **شكل اللعبة وتجربة المدينة**.

## ما تغير
- أصبحت الخريطة هي الواجهة الرئيسية للعبة.
- إزالة البطاقات الكبيرة من الشاشة الرئيسية.
- مبانٍ مرئية بأسلوب أقرب لألعاب بناء القواعد.
- قصر مركزي أكبر وواضح.
- طرق، أسوار، أراضٍ للبناء، ماء، أشجار، صخور ومحاصيل.
- شخصيات وحركة/عناصر بيئية داخل المدينة.
- شريط أدوات سفلي صغير للبناء والجيش والمتجر والأبحاث والعالم والمهام.
- الضغط على المبنى يفتح معلوماته بدل تحويل المدينة إلى Dashboard.
- ترقية المباني.
- بناء مبانٍ جديدة.
- موارد وجيش وحفظ محلي.
- تصميم مخصص للجوال.

## الاتجاه التالي
V4.0 هي الأساس البصري. التطوير التالي يمكن أن يضيف وضع بناء حر حقيقي بالسحب والإفلات، مؤقتات البناء والبنائين، مبانٍ أكثر، أسوار قابلة للتركيب، تحريك وحدات، خريطة عالم كاملة ومعارك.
