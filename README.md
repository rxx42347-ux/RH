# Empire Builder — V1.0

النسخة الشاملة الأساسية للعبة إدارة إمبراطورية، مهيأة للاستمرار كمشروع Android.

## الأنظمة
- عالم وخريطة.
- عدة مدن وإدارة مباني.
- سكان وسعادة وإسكان ونمو.
- موارد: غذاء، ماء، حديد، خشب، طاقة.
- اقتصاد وضرائب وأسعار تجارة.
- وظائف وإنتاج ومصانع وأسواق.
- حكومة وميزانيات وسياسات.
- جيش متعدد الفروع وتحسينات وتحصينات.
- حروب ومعارك وهدن وأهداف حرب.
- دبلوماسية واتفاقيات تجارية.
- شجرة أبحاث.
- أحداث ديناميكية.
- حفظ وتحميل محلي.
- واجهة مناسبة للجوال.

جميع ملفات المشروع في مجلد واحد لتسهيل الرفع من الهاتف.
