# رِيُو Ai — V1.0.0

أول نسخة من مشروع رِيُو Ai الجديد.

- واجهة عربية RTL.
- أسود وأبيض ورمادي.
- Mobile First.
- أسلوب محادثة بسيط قريب من تطبيقات المساعدات الحديثة.
- قائمة محادثات وحفظ محلي.
- مربع كتابة ومرفقات.
- لا توجد مفاتيح API داخل التطبيق.

**مهم:** هذه النسخة هي أساس الواجهة. الرد الحالي تجريبي، ولم يتم ادعاء ربط محرك AI حقيقي بعد. الخطوة التالية هي ربط API حقيقي من الخادم ثم اختبار المحادثة والصور والملفات.
