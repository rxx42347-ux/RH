# Empire Builder — V2.0

نسخة إعادة تصميم كبيرة للعبة Empire Builder.

## الهدف
اللعبة الآن مبنية حول تجربة استراتيجية مرئية شبيهة بألعاب بناء القواعد والإمبراطوريات:
- قاعدة/مدينة مرئية بدل لوحة أرقام فقط.
- مبانٍ مرئية قابلة للاختيار.
- نظام بناء وتكاليف موارد.
- موارد تتغير مع الوقت.
- جيش وتدريب وحدات.
- خريطة عالم ومناطق للاستكشاف والتجارة.
- مهام.
- دبلوماسية.
- أبحاث وتطوير.
- حفظ محلي.
- واجهة مهيأة للجوال.
- نفس بنية المشروع البسيطة في جذر المستودع.

## الملفات
- `index.html`
- `README.md`
- `CHANGELOG.md`
- `capacitor.config.ts`
- `package.json`

> V2.0 هي إعادة بناء لتجربة اللعب والواجهة، وليست نسخة نهائية من لعبة تجارية كاملة. المرحلة التالية يمكن أن تضيف خريطة أكبر، وضع بناء حر، تحريك وحدات، معارك حقيقية، اقتصاد أعمق، ومدن متعددة.
