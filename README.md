# Rio AI Studio V0.5.2 — Mobile Root Edition

هذه النسخة تصلح مشكلة نشر V0.5 السابقة مع الحفاظ على طريقة رفع الملفات من الجوال.

## ما تم إصلاحه

- إزالة إعداد `functions.runtime` الذي تسبب في خطأ Vercel: Function runtimes must have a valid version.
- تثبيت Node.js 24.x عبر `package.json`.
- استخدام إعداد Vercel متوافق مع ملفات الوظائف الموجودة في جذر المستودع، حتى لا نحتاج إنشاء مجلد `api`.
- إصلاح أخطاء JavaScript في `app.js` الناتجة عن نصوص متعددة الأسطر.
- الإبقاء على وظائف AI الحالية: Text→Video، Image→Video، Image، TTS، STT.
- الإبقاء على التحرير المحلي، المشاريع، القوالب، النصوص، الفلاتر، المقاسات، الصوت والتصدير المحلي.

## ملفات وظائف الخادم

- `ai.js`
- `status.js`
- `health.js`

هذه الملفات تُبنى كـ Vercel Node Functions عبر `vercel.json`، وتُربط بالمسارات:

- `/api/ai`
- `/api/status`
- `/api/health`

## المتغير السري

في Vercel يجب أن يكون لديك:

`FAL_KEY`

ولا تضع المفتاح داخل GitHub أو داخل JavaScript في المتصفح.

## ملاحظة

هذه النسخة تستخدم إعداد `builds` القديم فقط لتجنب الحاجة إلى مجلد `api` في سير عمل الرفع من الجوال. Vercel يوصي في المشاريع الجديدة باستخدام مجلد `api` مع إعدادات Functions الحديثة؛ هذا الإصدار اختار المسار القديم لأجل توافق طريقة الرفع الحالية.
