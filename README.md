# Rio AI Studio V0.6 — Core Platform

نسخة إعادة بناء كبيرة لواجهة Rio AI Studio مع تصميم أسود/أبيض ومساحات واسعة وتنظيم Mobile-first.

## ما تم تغييره
- إعادة تصميم الواجهة بالكامل بأسلوب monochrome أسود/أبيض.
- توزيع الأدوات في بطاقات منفصلة ومساحات واضحة.
- واجهة رئيسية + إنشاء + قوالب + مشاريع + حساب.
- محرر فيديو/صورة محلي: استيراد، معاينة، نص، فلاتر، مقاسات، صوت، حفظ وتصدير WebM.
- أدوات AI: نص→فيديو، صورة→فيديو، نص→صورة، نص→صوت.
- إصلاح مشكلة GitHub Pages التي كانت تستقبل HTML عند طلب `/api/*`: الواجهة الآن تستخدم خادم Vercel كـAPI عندما تعمل على GitHub Pages.
- إضافة CORS إلى وظائف Vercel.
- إزالة إعداد runtime الخاطئ من `vercel.json`؛ Node 24 مضبوط من `package.json`.
- الإبقاء على ملفات وظائف Vercel في الجذر لتناسب أسلوب الرفع الحالي من الجوال.

## ملاحظة مهمة
واجهة GitHub Pages يمكنها عرض التطبيق، لكن ميزات AI تحتاج خادم Vercel ومتغير البيئة `FAL_KEY`. لا تضع المفتاح داخل JavaScript.
