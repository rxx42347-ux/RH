# Empire Builder — V3.0

## اتجاه V3.0
إعادة بناء تجربة اللعب حول **مدينة استراتيجية قابلة للعب** بدل لوحة أرقام.

### الأنظمة الحالية
- خريطة مدينة مرئية مع طرق ومناطق طبيعية.
- مبانٍ متعددة واختيار المباني.
- بناء مبانٍ مع تكاليف موارد.
- مستوى لقصر المدينة يحدد التطور.
- إنتاج دوري للغذاء والخشب والماء والذهب.
- سكان وسعادة.
- جيش: مشاة، رماة، فرسان.
- تدريب القوات.
- خريطة عالمية أولية للاستكشاف والتوسع.
- اقتصاد ودخل وضرائب.
- دبلوماسية.
- أبحاث.
- مهام.
- حفظ محلي.
- واجهة جوال.

### الخطوات المستقبلية
- وضع بناء حر بالسحب والإفلات لكل مبنى.
- نظام بناء بزمن حقيقي وبنّائين.
- خريطة عالم حقيقية قابلة للتوسع.
- مدن متعددة.
- جيوش تتحرك على الخريطة.
- معارك فعلية.
- حصون وأسوار قابلة للتخطيط.
- تجارة بين المدن والممالك.
- تحالفات وحروب وأهداف.
- نظام تقدم طويل المدى.

V3.0 ليست لعبة تجارية مكتملة؛ هي قاعدة لعب فعلية يتم البناء عليها.
