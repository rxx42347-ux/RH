# Rio AI Studio — V0.1

نسخة واجهة Mobile-first تجريبية لتطبيق Rio AI Studio.

## ما يعمل فعلياً في هذه النسخة
- تنقل حقيقي بين الصفحات داخل التطبيق.
- واجهة رئيسية مرتبة وغير مزدحمة.
- شاشة إنشاء جديدة.
- شاشة قوالب.
- شاشة المشاريع.
- شاشة الحساب والاشتراكات.
- محرر فيديو تجريبي بواجهة Timeline.
- نوافذ إنشاء AI تفاعلية.
- زر تصدير يغير حالته.
- تصميم RTL عربي ومتجاوب مع الجوال.

## ملاحظة مهمة
هذه النسخة هي Prototype وظيفي للواجهة وتدفق الاستخدام. مولدات الفيديو/الصورة والصوت لم تُربط بعد بمحركات AI خارجية، لذلك لا يتم الادعاء بأنها تولد محتوى حقيقياً في هذه النسخة.

## التشغيل
ارفع الملفات إلى GitHub Pages أو افتح `index.html` مباشرة في المتصفح.

## الاتجاه
التصميم يستلهم نمط تطبيقات تحرير الفيديو الحديثة من حيث التنظيم والتدفق، مع هوية Rio الخاصة، وليس نسخاً حرفياً من تطبيق آخر.
