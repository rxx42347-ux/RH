# Rio AI Studio V0.6.1

نسخة Responsive UI مبنية على V0.6. تم تحسينها للجوال والتابلت وDesktop مع الحفاظ على واجهة الأسود والأبيض والرمادي.

## الملفات
- `index.html` الواجهة
- `style.css` التصميم والاستجابة
- `app.js` منطق التطبيق
- `ai.js` وظيفة AI على Vercel
- `status.js` متابعة الطلبات
- `health.js` فحص الخادم
- `vercel.json` إعدادات النشر
- `package.json` إعداد Node.js
- `CHANGELOG_V0.6.1.md` سجل التغييرات

## مهم
ارفع الملفات إلى جذر المستودع كما هي. لا تضع مفتاح `FAL_KEY` داخل ملفات JavaScript أو GitHub.
