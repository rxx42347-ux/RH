# رِيُو Ai — V1.0.4

نسخة الواجهة الرئيسية المعتمدة مبدئيًا.

- واجهة عربية RTL.
- هوية **Ai رِيُو** بصريًا: Ai على اليسار ورِيُو على اليمين.
- أسود وأبيض ورمادي.
- مساحات واسعة ومنظمة.
- خط طبيعي غير مبالغ فيه.
- شريط كتابة نظيف.
- الإرسال والميكروفون في الجهة اليسرى.
- قائمة مرفقات مرتبة.
- Mobile First.

**مهم:** هذه نسخة واجهة فقط؛ ربط محرك الذكاء الاصطناعي الحقيقي يأتي بعد اعتماد التصميم.
