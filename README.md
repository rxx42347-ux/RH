# Empire Builder — V0.4

نسخة V0.4 المطورة والمهيأة للاستمرار كمشروع Android.

## الجديد
- خريطة مملكة 6×4.
- نظام بناء موسع مع 7 أنواع مبانٍ.
- اقتصاد وضرائب ووظائف وخدمات.
- سكان وسعادة ومساكن ونمو سكاني.
- موارد: غذاء، حديد، خشب، طاقة.
- جيش مع مستويات قوة وتحسينات وتحصينات.
- دبلوماسية مع 3 دول مجاورة.
- شجرة بحث بثلاثة مسارات.
- أحداث شهرية عشوائية.
- حفظ/تحميل محلي.
- واجهة مناسبة للجوال.

جميع ملفات المشروع في مجلد واحد لتسهيل الرفع من الهاتف.
